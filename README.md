# Lock Screen Apps

This repository contains an Android app that lets you select up to 12 apps and show them in a lock screen notification for quick access.

## Features
- Select favorite apps from installed launchers
- Save selected apps locally
- Display app shortcuts in a lock screen notification
- Tap any icon to open the app directly
- Up to 12 apps supported

## Requirements
- Android Studio
- Android SDK 34
- JDK 17+

## Build
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Build > Build Bundle(s) / APK(s) > Build APK(s)

## Notes
This app is intended for Android devices and is not a desktop `.app` bundle. It produces an Android APK/AAB.
